# 📦 Carry & Throw!

A fun add-on that lets you pick up, throw, and stack mobs on top of each other in Minecraft Bedrock Edition!

***

## 🎮 HOW TO PLAY?

| Action              | Control                                                   |
| ------------------- | --------------------------------------------------------- |
| Pick up a mob       | Sneak and interact with a supported mob, both hands empty |
| Start/stop charging | Interact with the carried mob (toggle, no need to hold)   |
| Throw               | Hit the carried mob while charging                        |
| Cancel charge       | Sneak                                                     |
| Place               | Hit the carried mob without charging                      |

***

## ✨ Key Features

*   🧱 **Smart Block Collision:** Enjoy smooth, intelligent block collision while carrying a mob!
*   🥞 **Mob Towers:** Stack mobs on top of each other to build hilarious towers!
*   🫂 **Ride Players:** Hop on top of other players and ride on their shoulders!
*   ⚡ **Abilities:** Make your gameplay even more fun by using special abilities!

***

## ⚙️ Requirements & Compatibility

*   🟢 **No Experimental Settings:** Play right away without needing **Beta APIs** or any other experimental toggles.

***

## 🐾 Supported Mobs

**All Mobs Supported** — Every mob, player, and vehicle (minecarts, boats, armor stands, etc.) in the game can be carried, **except the Ender Dragon and Wither**.

## 🧊 Supported Blocks

**All Blocks Supported** — You can now pick up and carry every block in the game *(Note: Not all blocks have a custom 3D texture when carried)*.
